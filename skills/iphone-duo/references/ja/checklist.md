# 移行と検証

[한국어](../checklist.md) | [English](../en/checklist.md) | 日本語

該当する項目だけ実行し、合格 / 失敗 / 未実施 / 対象外で記録します。SDK 不足を理由に、可能な一般的な適応型 UI 改善まで止めません。

## 実装前後

- [ ] プロジェクト指示、既存の変更、scheme、デプロイ対象、実際の SDK を確認した。
- [ ] 変更前後のビルド結果を比較し、既存エラーと回帰を区別した。
- [ ] 画面全体のサイズ・機器種別の仮定と、非対称 inset の計算を点検した。
- [ ] 新 API のモジュール・シグネチャ・availability と旧 OS の代替動作を確認した。
- [ ] サイズ変更後も navigation path、選択、入力途中の内容、スクロール・再生位置が保持される。

## 観察する動作

| 状況 | 確認 |
|---|---|
| 狭い/広い幅、低い高さ | 切れ・重なり・過剰な空白、主要操作へのアクセス |
| Duo の開閉・部分的な折り曲げ・回転 | 操作要素の遮蔽、状態保持、繰り返し切り替えの安定性 |
| マルチタスクの左右配置・リサイズ | 非対称 safe area、現在のウインドウ基準の座標 |
| キーボード・シート・ポップオーバー | 入力と完了/取消へのアクセス、anchor の有効性 |
| 大きい Dynamic Type・長い翻訳・RTL | 読み上げ・探索順序、テキストの切れ |
| VoiceOver・Reduce Motion/Transparency | focus 保持、操作名、可読性 |
| 通常の iPhone・対応 iPad・最古の対応 OS | 既存画面と代替動作の回帰 |
| 該当アプリの複数ウインドウ・外部画面 | 状態の独立、接続解除、要求失敗 |
| 該当アプリのカメラ | 拒否・中断・復帰・開閉・録画、保存結果の向き |

利用できる simulator/実機で代表的なユーザーフローを実行します。Duo がなければ通常機器のリサイズ検証は部分検証と記録します。スクリーンショットだけで状態保持やアクセシビリティの検証を代替しません。

回帰リスクのある状態遷移や代替動作には、振る舞いを確認するテストを追加します。文言や実装構造をそのまま比較するテストは作りません。変更に関係する既存テストとビルドを実行します。

## 報告形式

- 変更: ファイル、動作、理由
- 確認: SDK / scheme / destination / 実行コマンド / 結果
- 未実施: 機器・runtime など不足する条件と再現手順
- 次の対応: 未確認 API や失敗した検証に必要な具体的な措置
